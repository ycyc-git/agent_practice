## 🔍 더 알아보는 프로그래머 직업병 대백과

### 1. 안경 편 (심화)

앞서 말씀드렸듯이, 프로그래머가 안경을 쓰는 이유는 C#을 보기 때문입니다.  
그런데 사실 더 깊은 이유가 있습니다.

- **Python**을 쓰면 뱀을 보게 되어 심장이 약해집니다.
- **Java**를 쓰면 커피를 너무 마셔 손이 떨립니다.
- **Rust**를 쓰면 컴파일 에러와 싸우느라 눈이 충혈됩니다.
- **JavaScript**를 쓰면 `undefined is not a function`을 보고 정신줄을 놓습니다.

결론: 어떤 언어를 써도 안경은 필수입니다.

---

### 2. 자세 편

프로그래머의 자세는 크게 세 가지로 나뉩니다.

1. **버그가 없을 때**: 의자에 깊숙이 앉아 팔짱을 낀 채 만족스러운 표정
2. **버그가 있을 때**: 모니터에 코를 박고 눈을 가늘게 뜨는 자세
3. **배포 직전**: 기도하는 자세 (종교 불문)

---

### 3. 식습관 편

프로그래머의 주식은 다음과 같습니다.

| 시간대 | 메뉴 |
|--------|------|
| 아침 | 커피 (식사 대용) |
| 점심 | 커피 + 샌드위치 (혹은 커피만) |
| 저녁 | 야근 중이면 치킨, 퇴근했으면 치킨 |
| 새벽 | 에너지 드링크 + 과자 |
